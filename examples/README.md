# Examples and solutions

Two directories, two purposes:

- **`examples/`** — the exact files as each lesson presents them, so you can copy
  rather than transcribe. Read-only in spirit: if a lesson changes, these change.
- **`solutions/`** — the working answer key, including the parts a lesson leaves to
  you (the full plugin, not just the fragment), for diffing when you get stuck.

## Status

Both directories are currently **empty placeholders**. They are populated as part
of the verification pass — see the backlog in [VERIFIED.md](../VERIFIED.md).

Until then, create the files yourself under [`../plugins/`](../plugins/README.md) as
each lesson instructs. That is not a worse way to learn; typing the code is where
most of the understanding happens.

## Planned layout

Once populated, the structure mirrors the lessons:

```
examples/
  l1/hello.ts
  l1.patch.yml
  l2/wordcount.ts
  l2.patch.yml
  ...
solutions/
  l1/...
  l9/...
```
